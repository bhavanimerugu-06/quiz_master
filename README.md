# Quiz Master 🎯

## About the Project
Quiz Master is a Flutter-based quiz application developed using Dart. It allows users to test their knowledge through multiple-choice questions across different categories.

## Features
- Multiple quiz categories
- Interactive multiple-choice questions (MCQs)
- Score calculation and tracking
- Progress indicator during quizzes
- Answer feedback and explanations
- Light mode and dark mode
- User profile form with validation
- Navigation using Navigator and named routes
- State management using Provider
- Custom reusable widgets
- Animated question transitions

## Technologies Used
- Flutter
- Dart
- Provider
- Material Design 3
- Visual Studio Code

## How to Run the Project

### Prerequisites
- Flutter SDK installed
- Dart SDK (included with Flutter)
- Visual Studio Code or Android Studio
- Chrome browser or Windows desktop development setup

### Installation Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/bhavanimerugu-06/quiz_master.git
   ```

2. Open the project folder:

   ```bash
   cd quiz_master
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application in Chrome:

   ```bash
   flutter run -d chrome
   ```

   Or run on Windows desktop:

   ```bash
   flutter run -d windows
   ```

## Project Structure
